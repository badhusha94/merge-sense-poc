MergeSense PR Reviewer

High-Level Workflow — AI-Powered Code Review & Refactor Pipeline

Trigger
Trigger

Pull Request Opened / Updated

A PR targeting main is opened, synchronized, or manually dispatched.

Filter

Path Filter

Only proceeds when changes touch modern-app/api/** or modern-app/scripts/**.

Preparation
Automated

Build PR Diff

Generates pr.diff comparing the PR branch against main.

Automated

Collect Main Codebase

Concatenates all modern-app/api/**/*.cs from the base branch into main_code.cs.

Automated

Load Review Rules

Reads .ai/review-rules.json for active check layers and thresholds.

Analysis
AI Engine

Run analyze.js

Core analysis engine processes the diff and main code through multiple review layers.

Review Checks Performed
Checks
AI — Embeddings + LLM

Semantic Duplication

Compares PR methods to main via embeddings (≥50% similarity) with LLM confirmation.

AI — Embeddings + LLM

Intra-PR Duplication

Detects duplicate logic within the PR's own changed files.

AI — LLM

Logic Safety

Flags changes that may alter existing business logic in modified methods.

Deterministic

Script Rules

Jira ticket in filename, developer header, DB naming prefixes, indexes for new tables.

Deterministic

C# Rules

ApiController attribute, versioned routes, ALL_CAPS constants, no Console, AuthFilter, etc.

Deterministic

Constant & DTO Duplication

Same constant values or DTO property shapes appearing across the codebase.

AI + Deterministic

C# Learning Tips

Suggests modern C# idioms — string interpolation, records, pattern matching, etc.

Output
Output

Generate findings.json

Structured findings with type, severity, title, description, file, line, and cursor prompt.

Automated

Post PR Comments

post-pr-comments.js publishes each finding as an inline review comment on the PR.

Hint

Suggest Refactor

Adds a comment inviting the developer to run /ai-apply-refactor if findings exist.

Developer
Human

Review Findings

Developer reads inline comments, decides whether to fix manually or invoke AI refactor.

Decision

Fix Manually or Invoke AI?

Comment /ai-apply-refactor on the PR to trigger the automated refactor pipeline.

Alternate Flow — AI Apply Refactor

Triggered when a developer comments /ai-apply-refactor on the PR

Trigger

Comment Detected

/ai-apply-refactor comment on the PR triggers ai-apply-refactor.yml.

Gate

Human Approval

Requires approval via the refactor-approval GitHub environment before proceeding.

AI Engine

Re-analyze & Apply

Runs analyze.js for fresh findings, then apply-refactor.js to generate fixes via OpenAI.

Automated

Commit & Push

Refactored files are committed and pushed to the PR branch automatically.

Automated

Re-trigger Review

Dispatches ai-review.yml on the updated branch so checks run again end-to-end.
